📋 CSV Format Guide

Required columns
name Glass identifier (any text)
Optional meta columns
source experimental / simulation / literature
comp_type wt_pct / mol_pct / at_pct
notes Free-text note
Oxide columns (any subset)

Property columns (any)
Any other column is treated as a property measurement. Common examples:
density tg_celsius refractive_index_nD thermal_expansion_coeff youngs_modulus_GPa
Example
name,source,notes,comp_type,SiO2,Na2O,CaO,MgO,Al2O3,density,tg_celsius
Soda-lime std,experimental,Batch 42,wt_pct,72.5,12.8,9.1,3.9,1.1,2.49,557
BSil 7740,literature,Corning,wt_pct,80.5,4.0,0,0,2.5,2.23,525
R&D sample A,experimental,,mol_pct,65.0,15.0,12.0,8.0,0,,,
💡 Empty cells are ignored. Leave property columns empty if not measured. Column order doesn't matter.
